# agent-dash
Claude mod which displays info about sessions, usage limits , ascii art, and more

## Installation

1. Checkout the repo in the `~/.claude/skills/agent-dash`
2. Run `/reload-skills` in the Claude code
3. When in session, run `/dash` to activate it
